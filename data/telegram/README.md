# Похідний архів @war_monitor

Публічне джерело: https://t.me/s/war_monitor. Збір 12.10.2026 UTC; вибраний фрагмент публікацій 18.02–11.10.2026. Точні межі, аномалії та словник — у `source_audit.json`.

`message_versions.csv.gz` містить ID, посилання, published_at, фактичний observed_at, видиму позначку редагування, наявність тексту, похідні прапорці слів/технічних робіт і SHA256 тексту. Це не архів оригінальних історичних редакцій. Відсутність edited не доводить незмінності: Telegram має edit_hide. Пропущені ID не підтверджують причини відсутності повідомлень.

`captures.json` фіксує URL сторінки, час отримання та SHA256 повного HTML. Локальні HTML у `raw/` не входять у Git/ZIP. `checksums.json` перевіряє зафіксовані похідні файли. Відтворення моделей із них працює без мережі; незалежне повторне виділення тексту потребує локальних HTML або нового збору, який може відрізнятися.
